# Session 7 — Encapsulation and Access Control

## Practice
- PiggyBank: private savings and validated deposit/withdraw operations.
- Scorecard: private answer array and score-only access.
- NameTag: immutable nickname derived from a full name.
- Locker: write-only combination with old-code validation.
- AttendanceSheet: private names, duplicate prevention and count/lookups.

## Assignment
- Character: health clamped between zero and fixed maximum.
- Playlist: defensive copy of private song array.
- PasswordChecker: immutable private password and strength-only result.
- TrafficLight: controlled red-green-yellow state transitions.
- Cart: private prices, final ID, computed total and item count.
