# Session 3 — Control Flow Category C Assignment

Contains all 15 problems across Levels 1–3 from the Week 3 Category C Assignment PDF. Each problem is a separate Java class in `src/main/java/control_flow/assigment_problems/`.

Level 1: voting eligibility, number classifier, count-up loop, natural-number sum, day-name switch.
Level 2: attendance grade classifier, login attempts, skip multiples of three, switch calculator, prime checker.
Level 3: number pyramid, ATM PIN retry, traffic signal simulator, first-valid multiplication table, guess-the-number game.
