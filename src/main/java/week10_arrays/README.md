# Week 10 — Array Coding Assignments

## Assignment problems
- **SecondBestScore** — second-highest distinct score in one pass without sorting; O(n) time and O(1) extra space.
- **DutyRosterRotation** — right rotation using `k % n`; O(n) time and O(n) extra space.
- **ExamScoreBandCounter** — counts scores in an inclusive band using two binary searches; O(log n) time and O(1) extra space.
- **ClassAttendanceTracker** — counts present days and the longest attendance streak in one pass; O(n) time and O(1) working space.
- **BusiestBusRow** — finds the row with the largest seat total, preserving the earliest row on ties; O(r × c) time and O(1) working space.

Each Java file includes a runnable example or reads the input required by the problem.
