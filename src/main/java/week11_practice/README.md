# Week 11 — Category C Practice Problems

Solutions for all six problems in `CATEGORY-C-PRACTICE-PROBLEMS.pdf`:

1. **CampusStaffSalary** — inheritance and runtime polymorphism with a Staff array.
2. **ClassReportCard** — validation through `setMarks`, grade calculation, and early-stopping bubble sort.
3. **LibraryReturnDesk** — array stack and circular array queue, each with capacity 3.
4. **PaymentProcessing** — PaymentMode interface and cash, card, and UPI implementations.
5. **WeeklyRainfallAnalysis** — seven-day rainfall summary using a double array and loops.
6. **HostelElectricityBill** — slab-based billing, fixed meter charge, and invalid-reading handling.

Each program reads the input format described in the supplied PDF. Complexity notes are included in the source.
