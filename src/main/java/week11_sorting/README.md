# Week 11 — Sorting Algorithm Assignments

1. **HeightLineUp** — bubble sort in ascending order; print every sweep and stop after a sweep with no swaps.
2. **PrizeTable** — selection sort in descending order; count only swaps that actually occur.
3. **LibraryBookShelf** — insertion sort; print the shelf after each insertion.
4. **QueueInOrder** — find the first index where a token is smaller than its predecessor.
5. **DiceThrowTally** — counting sort for die values 1 through 6; print each frequency.

The sorting tasks are implemented manually; no call to `Arrays.sort()` is used.
