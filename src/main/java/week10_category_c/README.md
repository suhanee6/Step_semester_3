# Week 10 — Category C Coding Practice

Solutions for Part A (Coding Problems 1–10) of `CATEGORY-C-DATA-STRUCTURE_PRACTICE.pdf`:

1. **VowelConsonantCounter** — count vowels and consonants.
2. **WordReverserPalindromeChecker** — reverse a word and check whether it is a palindrome.
3. **EvenOddCounter** — count even and odd values in a list.
4. **InPlaceArrayReversal** — reverse an array in place with two pointers.
5. **DigitSumAndNumberReversal** — calculate digit sum and reverse a positive integer.
6. **PrimeNumberChecker** — test primality up to the square root.
7. **FactorialCalculation** — calculate factorial for values from 0 to 20.
8. **StudentGradeAssignment** — assign grades using the supplied thresholds.
9. **LeapYearDetector** — apply the leap-year rules.
10. **StudentResultCardGenerator** — calculate average marks and print a student's result.

The source PDF's Part B quiz and Part C concept questions are not included in this coding-solutions folder.
